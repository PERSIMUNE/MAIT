# MAIT — Medical Artificial Intelligence Toolbox

MAIT is a Python workflow for explainable machine learning on tabular research data, supporting binary classification, survival analysis, and regression.

This Space introduces MAIT and links to its interactive Streamlit configuration app. Configure an analysis in the app, export a Python script, and run it in your local analysis environment.

- [Open the configuration app](https://maitconfig.streamlit.app/)
- [Quick start](https://persimune.github.io/MAIT/QuickStart.html)
- [Documentation](https://persimune.github.io/MAIT/intro.html)
- [Source code and installation](https://github.com/PERSIMUNE/MAIT)
- [Methods paper](https://doi.org/10.48550/arXiv.2501.04547)
- [Python package](https://pypi.org/project/mait-pipeline/)

Developed by Ramtin Zargari Marandi, PhD, during his postdoctoral work at PERSIMUNE–CHIP, Rigshospitalet, Copenhagen University Hospital. Full project credits and citation information are available in the linked documentation and repository.

The Space uses static HTML and does not require paid compute. Its source is maintained in the MAIT repository under `community/huggingface`. The MAIT license and the Open Sans font license are included alongside the page.
